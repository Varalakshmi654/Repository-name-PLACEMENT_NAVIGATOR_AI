01 · FOUNDATION

📊 What is Data Analysis?

Data Analysis is the process of collecting, cleaning, transforming and examining data to discover useful information and support decisions.

Simple Example

Imagine a company has sales data for one year. A Data Analyst can analyze that data to find:

  • Which product sells the most?
  • Which month has the highest sales?
  • Which region performs best?
  • Where are sales decreasing?
🔄 Data Analysis Lifecycle

Collect Data → Clean Data → Explore Data → Analyze Data → Visualize Data → Communicate Insights

🎤 Interview Question

What is Data Analysis?

Data Analysis is the process of examining, cleaning and transforming data to identify useful patterns and insights that help in decision making.
02 · DATA PREPARATION

🧹 Data Cleaning

Data cleaning is the process of identifying and correcting problems in raw data before performing analysis.

Common Data Quality Problems
  • Missing values
  • Duplicate records
  • Incorrect data types
  • Invalid values
  • Inconsistent formats
  • Outliers
🐍 Example using Pandas 
import pandas as pd

df = pd.read_csv("sales.csv")

df.drop_duplicates(inplace=True)

df = df.dropna()
🧪 Scenario

Your dataset contains duplicate customer records. What would you do?

First I would identify which columns define a duplicate record. Then I would remove duplicate records while keeping the original dataset as a backup.
03 · EXPLORATORY ANALYSIS

🔍 Exploratory Data Analysis

Exploratory Data Analysis, or EDA, is used to understand the structure of a dataset and discover patterns, relationships and unusual values.

Important Measures

Mean: Average value of the data.

Median: Middle value after sorting the data.

Mode: Most frequently occurring value.

Correlation: Measures the relationship between variables.

🐍 Pandas Example 
df.describe()

df["salary"].mean()

df["age"].median()

df["department"].value_counts()
🎤 Interview Question

Why is EDA important?

EDA helps us understand the dataset before building models or making decisions. It helps identify patterns, missing values, outliers and relationships between variables.
04 · PYTHON ANALYTICS

🐍 Python for Data Analysis

Python is widely used for data analysis because libraries such as Pandas and NumPy make data manipulation and numerical analysis easier.

Important Libraries
  • Pandas – Data manipulation and analysis
  • NumPy – Numerical operations
  • Matplotlib – Data visualization
  • Seaborn – Statistical visualization
📄 Reading a CSV File 
import pandas as pd

df = pd.read_csv("employees.csv")

print(df.head())
🔎 Filtering Data 
high_salary = df[df["salary"] > 50000]

print(high_salary)
💡 Interview Tip

Don't just say "I know Pandas." Explain how you used Pandas to clean, filter, group and analyze a dataset.

05 · DATA VISUALIZATION

📈 Data Visualization

Data visualization converts data into charts and graphs so that patterns and trends can be understood quickly.

📊 Choosing the Right Chart

Bar Chart: Compare categories.

Line Chart: Show trends over time.

Pie Chart: Show proportions of a whole.

Histogram: Understand distribution of numeric data.

Scatter Plot: Examine relationships between two variables.

Example

If you want to compare sales across five products, a Bar Chart would be a suitable choice.

If you want to show monthly sales for one year, a Line Chart would usually be more suitable.

🎤 Interview Question

Which chart would you use to show a monthly sales trend?

A Line Chart is suitable because it clearly shows how values change over time.
06 · BUSINESS ANALYTICS

💼 Turning Data into Business Insights

A Data Analyst should not stop after creating charts. The important step is explaining what the data means and how it can support decisions.

Example

Suppose analysis shows that sales decreased by 20% in one region during the last quarter.

A useful insight could be:

"Sales in Region A decreased significantly during the last quarter. The company should investigate customer demand, pricing and competition in that region."

📌 Important Business Concepts
  • KPI
  • Sales Performance
  • Customer Behaviour
  • Trends
  • Business Recommendations
🎤 Interview Question

What is a KPI?

KPI stands for Key Performance Indicator. It is a measurable value used to evaluate the performance or progress of a business objective.
