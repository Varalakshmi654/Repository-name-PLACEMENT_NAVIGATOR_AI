01 · DATA STRUCTURE

📋 List

A list is an ordered and mutable collection in Python. It can store multiple values and allows duplicate elements.

Ordered Mutable Duplicates Allowed Indexed 
numbers = [10, 20, 30, 40]

print(numbers[0])

numbers.append(50)

print(numbers)
💡 Interview Tip: If the interviewer asks why you use a list, explain that it is useful when you need an ordered and changeable collection.
02 · DATA STRUCTURE

📦 Tuple

A tuple is an ordered collection that cannot be changed after it is created.

Ordered Immutable Duplicates Allowed Indexed 
student = ("Varalakshmi", 21, "Data Science")

print(student[0])
💡 Interview Tip: The key difference to remember is: List → Mutable Tuple → Immutable
03 · DATA STRUCTURE

🔵 Set

A set is an unordered collection of unique elements. Duplicate values are automatically removed.

Unique Values Unordered Mutable 
numbers = {10, 20, 20, 30}

print(numbers)
💡 Interview Tip: If you need to remove duplicate values from a collection, a set can be useful.
04 · DATA STRUCTURE

🗂️ Dictionary

A dictionary stores data as key-value pairs. It is useful when information needs to be accessed using meaningful keys.

Key-Value Mutable Fast Lookup 
student = {
    "name": "Varalakshmi",
    "course": "Data Science",
    "year": 3
}

print(student["name"])
💡 Interview Tip: A common interview question is: "What is the difference between a list and a dictionary?" Remember: List uses indexes, while dictionary uses keys.

🎤 Interview Questions

Practice explaining the concepts in simple interview English.

01. What is the difference between a list and a tuple?

A list is mutable, which means its elements can be changed. A tuple is immutable, which means it cannot be changed after creation.

02. What is a set used for?

A set is mainly useful when we need a collection of unique elements and want to remove duplicates.

03. What is a dictionary in Python?

A dictionary is a mutable collection that stores information using key-value pairs.

04. How can you remove duplicates from a list?

One simple approach is to convert the list into a set. For example:

unique_values = list(set(values))
