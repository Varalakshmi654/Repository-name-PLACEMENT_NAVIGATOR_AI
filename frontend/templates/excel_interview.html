📚 Theory Questions

Understand the concepts before explaining them in an interview.

QUESTION 01

What is the difference between a workbook and a worksheet in Excel?

A workbook is an Excel file that can contain multiple worksheets.

A worksheet is an individual spreadsheet inside the workbook where data is stored and analyzed.
QUESTION 02

What is the difference between COUNT, COUNTA and COUNTBLANK?

COUNT counts cells containing numbers.

COUNTA counts non-empty cells.

COUNTBLANK counts empty cells.
QUESTION 03

What is a Pivot Table?

A Pivot Table is an Excel tool used to summarize, analyze and organize large datasets quickly.

It can be used to calculate totals, counts, averages and compare data across categories.
QUESTION 04

What is the difference between VLOOKUP and XLOOKUP?

VLOOKUP searches for a value in the first column of a table and returns a value from another column.

XLOOKUP is a more flexible lookup function that can search in different directions and provides easier handling of missing values.
QUESTION 05

What is the difference between sorting and filtering?

Sorting changes the order of data, such as ascending or descending order.

Filtering displays only the rows that satisfy selected conditions.

🧠 Scenario Questions

These questions test how you would use Excel in real workplace situations.

SCENARIO 01

You receive a dataset containing duplicate customer records. How would you clean it?

I would first inspect the dataset and identify the columns that uniquely identify a customer.

Then I would use Excel's Remove Duplicates feature after making a backup of the original data.
SCENARIO 02

Your manager wants monthly sales by department. How would you prepare the report?

I would clean and organize the sales data first.

Then I would create a Pivot Table using department and month as categories and sales as the value.

Finally, I would use a suitable chart to present the results clearly.
