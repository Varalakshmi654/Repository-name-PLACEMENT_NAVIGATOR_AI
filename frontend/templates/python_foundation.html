CONCEPT 01

📦 Variables

A variable is a name used to store a value in a Python program. 

name = "Varalakshmi"
age = 21
💡 Interview Tip: Explain that Python variables do not require explicit type declaration.
CONCEPT 02

🔤 Data Types

Python provides different data types to represent different kinds of values.

int float str bool list tuple set dict 
age = 21
price = 99.5
name = "Python"
is_ready = True
CONCEPT 03

➕ Operators

Operators are used to perform operations on values and variables.

Arithmetic Comparison Logical Assignment 
a = 10
b = 5

print(a + b)
print(a > b)
CONCEPT 04

⌨️ Input & Output

Python uses input() to receive information from the user and print() to display output. 

name = input("Enter your name: ")

print("Hello", name)

🎤 Interview Questions

Practice answering these questions in simple interview English.

01. What is Python?

Python is a high-level, interpreted and general-purpose programming language known for its simple and readable syntax.

02. What are variables in Python?

Variables are names used to store values in a Python program.

03. Does Python require variable declaration?

No. Python does not require explicit variable declaration. The type is determined from the value assigned to the variable.
