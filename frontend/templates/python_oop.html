01 · OOP FOUNDATION

🧱 Class & Object

A class is a blueprint for creating objects. An object is an instance of a class. 

class Student:

    def display(self):
        print("Data Science Student")


student1 = Student()

student1.display()
💡 Interview Tip: A simple way to remember it:

Class = Blueprint
Object = Real instance created from that blueprint
02 · INITIALIZATION

🏗️ Constructor — __init__()

The __init__() method is commonly used to initialize an object's attributes when an object is created. 

class Student:

    def __init__(self, name, course):

        self.name = name
        self.course = course


student1 = Student(
    "Varalakshmi",
    "Data Science"
)

print(student1.name)
print(student1.course)
💡 Interview Tip: If asked about __init__(), explain that it is used to initialize object attributes when an object is created.
03 · OOP PRINCIPLE

🔒 Encapsulation

Encapsulation means keeping data and the methods that operate on that data together inside a class and controlling how the data is accessed. 

class Student:

    def __init__(self):

        self.__marks = 90

    def get_marks(self):

        return self.__marks


student = Student()

print(student.get_marks())
💡 Interview Tip: The double underscore is commonly used for name-mangled attributes in Python.
04 · OOP PRINCIPLE

🌳 Inheritance

Inheritance allows a child class to reuse attributes and methods of a parent class. 

class Person:

    def speak(self):

        print("I can speak")


class Student(Person):

    def study(self):

        print("I can study")


student = Student()

student.speak()
student.study()
💡 Remember: Parent class → Base class
Child class → Derived class
05 · OOP PRINCIPLE

🔄 Polymorphism

Polymorphism means the same interface or method name can behave differently for different objects. 

class Dog:

    def sound(self):

        print("Bark")


class Cat:

    def sound(self):

        print("Meow")


for animal in [Dog(), Cat()]:

    animal.sound()
💡 Interview Tip: Think: One method → Different behavior
06 · OOP PRINCIPLE

🎭 Abstraction

Abstraction focuses on showing the essential functionality while hiding unnecessary implementation details. 

from abc import ABC, abstractmethod


class Vehicle(ABC):

    @abstractmethod
    def start(self):
        pass


class Car(Vehicle):

    def start(self):

        print("Car started")


car = Car()

car.start()
💡 Interview Tip: In Python, abstraction can be implemented using the abc module and abstract methods.
07 · INHERITANCE

🔁 Method Overriding

Method overriding happens when a child class provides its own implementation of a method already defined in the parent class. 

class Parent:

    def show(self):

        print("Parent method")


class Child(Parent):

    def show(self):

        print("Child method")


obj = Child()

obj.show()
