01 · FOUNDATION

📊 Excel Basics

Excel is a spreadsheet application used to store, organize, calculate and analyze data.

Important Concepts

Workbook → Complete Excel file

Worksheet → Individual sheet inside a workbook

Cell → Intersection of a row and column

Row → Horizontal collection of cells

Column → Vertical collection of cells

🎤 Interview Question

What is the difference between a workbook and a worksheet?

A workbook is the complete Excel file, while a worksheet is an individual sheet inside that workbook.
02 · FORMULAS

🧮 Excel Formulas & Functions

Formulas help perform calculations and analyze data quickly.

Common Functions

SUM() – Adds values

AVERAGE() – Calculates average

MIN() – Finds minimum value

MAX() – Finds maximum value

COUNT() – Counts numeric cells

=SUM(B2:B10)
💻 Practice

Write a formula to calculate the total sales from B2 to B20.

=SUM(B2:B20)
03 · LOGICAL FUNCTIONS

🧠 IF, COUNTIF & SUMIF

Logical functions help make decisions and calculate values based on conditions.

IF Example 
=IF(B2>=50,"Pass","Fail")
This formula checks whether the value in B2 is greater than or equal to 50.
COUNTIF Example 
=COUNTIF(B2:B100,">50")
Counts values greater than 50.
🎤 Interview Tip

Explain not only the formula but also where you would use it in a real dataset.

04 · LOOKUP

🔎 VLOOKUP & XLOOKUP

Lookup functions help retrieve information from another table or range.

VLOOKUP Example 
=VLOOKUP(A2,E2:G100,3,FALSE)
XLOOKUP Example 
=XLOOKUP(A2,E2:E100,G2:G100)
🎤 Interview Question

Why is XLOOKUP considered more flexible than VLOOKUP?

XLOOKUP provides more flexible lookup capabilities and can search in different directions without requiring the lookup column to be the first column.
05 · DATA ANALYSIS

↕️ Sorting & Filtering

Sorting changes the order of data, while filtering displays only records matching selected conditions.

Example

You have 1,000 employee records and want to see only employees from the IT department.

Use the Excel Filter option on the Department column.

💡 Interview Tip

Always mention that filtering does not delete the other records; it temporarily hides records that do not match the condition.

06 · DATA VISUALIZATION

📊 Pivot Tables & Charts

Pivot Tables summarize large datasets and help identify patterns and trends.

Example

Suppose a company has sales data containing:

Employee · Department · Month · Sales

A Pivot Table can summarize total sales for each department.

🎤 Interview Question

Why would you use a Pivot Table?

A Pivot Table is useful for quickly summarizing, grouping and analyzing large datasets.
07 · DATA CLEANING

🧹 Excel Data Cleaning

Data cleaning prepares raw data for accurate analysis.

Common Cleaning Tasks

Remove duplicate records

Handle blank values

Find & Replace incorrect values

Use Text to Columns when required

Standardize inconsistent data

🧪 Scenario

You receive a customer dataset containing duplicate records. What would you do?

First, I would inspect the dataset and identify which columns define a duplicate. Then I would use Excel's Remove Duplicates feature after keeping a backup of the original dataset.

💡 Excel Interview Tip

Don't just say that you know Excel. Explain how you used formulas, lookup functions, Pivot Tables and data-cleaning techniques to solve a real problem.
