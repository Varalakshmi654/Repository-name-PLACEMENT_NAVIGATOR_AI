01 · SQL BASICS

🗄️ What is SQL?

SQL stands for Structured Query Language. It is used to communicate with relational databases and retrieve, insert, update and delete data.

💡 Interview Tip: Explain SQL in simple words:

"SQL is used to store, retrieve and manipulate data in relational databases."

02 · SELECT & WHERE

🔎 SELECT Statement

SELECT is used to retrieve data from a table. 

SELECT name, age
FROM students;

WHERE Clause

WHERE filters rows based on a condition. 

SELECT *
FROM students
WHERE age > 20;

03 · ORDER BY

↕️ Sorting Data

ORDER BY is used to sort query results. ASC sorts in ascending order and DESC sorts in descending order. 

SELECT *
FROM students
ORDER BY age DESC;

04 · GROUP BY & AGGREGATE FUNCTIONS

📊 Aggregate Functions

Common aggregate functions include:

COUNT() · SUM() · AVG() · MIN() · MAX() 

SELECT department,
       COUNT(*) AS total_students
FROM students
GROUP BY department;
💡 Remember: GROUP BY creates groups of rows so that aggregate functions can be applied to each group.

05 · JOINS

🔗 SQL Joins

Joins are used to combine related data from multiple tables.

Common joins:

INNER JOIN · LEFT JOIN · RIGHT JOIN · FULL JOIN 

SELECT
    students.name,
    departments.department_name

FROM students

INNER JOIN departments
ON students.department_id
   = departments.department_id;
💡 Interview Tip: INNER JOIN returns matching records from both tables.

LEFT JOIN keeps all rows from the left table and matching rows from the right table.

06 · SUBQUERIES

🔍 Subquery

A subquery is a query written inside another query. 

SELECT name, salary
FROM employees
WHERE salary >
(
    SELECT AVG(salary)
    FROM employees
);
💡 This query finds employees whose salary is greater than the average salary.

07 · CASE STATEMENT

🧠 CASE

CASE allows conditional logic inside SQL queries. 

SELECT
    name,
    marks,

    CASE
        WHEN marks >= 90 THEN 'Excellent'
        WHEN marks >= 60 THEN 'Good'
        ELSE 'Needs Improvement'
    END AS result

FROM students;

🎤 08 · SQL INTERVIEW QUESTIONS

QUESTION 01

What is the difference between WHERE and HAVING?

WHERE filters individual rows before grouping. HAVING filters groups after GROUP BY is applied.
QUESTION 02

What is a primary key?

A primary key uniquely identifies each row in a table. A table has one primary key, which can consist of one or more columns.
QUESTION 03

What is a foreign key?

A foreign key is a column or set of columns that references a key in another table, commonly used to establish relationships between tables.
QUESTION 04

What is the difference between DELETE and TRUNCATE?

DELETE removes selected rows and can use a WHERE condition. TRUNCATE removes all rows from a table and is generally used when the entire table data needs to be cleared.
QUESTION 05

What is the difference between INNER JOIN and LEFT JOIN?

INNER JOIN returns rows where matching data exists in both tables. LEFT JOIN returns all rows from the left table and matching rows from the right table.

💻 09 · SQL CODING PRACTICE

QUERY 01

Find all employees whose salary is greater than 50,000. 

SELECT *
FROM employees
WHERE salary > 50000;
QUERY 02

Find the average salary of employees. 

SELECT AVG(salary)
FROM employees;
QUERY 03

Count the number of employees in each department. 

SELECT department,
       COUNT(*) AS employee_count

FROM employees

GROUP BY department;
