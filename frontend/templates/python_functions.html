01 · FOUNDATION

⚙️ What is a Function?

A function is a reusable block of code that performs a specific task. Functions help us avoid repeating the same code multiple times. 

def greet():
    print("Hello, Varalakshmi!")

greet()
💡 Interview Tip: In an interview, you can say:

"A function is a reusable block of code designed to perform a specific task."
02 · PARAMETERS

📥 Parameters & Arguments

Parameters are variables defined in a function. Arguments are the actual values passed to the function when it is called. 

def greet(name):
    print("Hello", name)

greet("Varalakshmi")
💡 Remember: Parameter → variable in function definition.
Argument → actual value passed during function call.
03 · OUTPUT

🔄 Return Statement

The return statement sends a value back from a function to the place where the function was called. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)
💡 Interview Tip: A function can use return when we want to send the calculated result back to the caller.
04 · FUNCTION ARGUMENTS

🎯 Default Arguments

A default argument allows a function parameter to have a predefined value when no value is supplied. 

def greet(name="Student"):
    print("Hello", name)

greet()

greet("Varalakshmi")
💡 Interview Tip: Default arguments make functions flexible because the caller does not always have to provide a value.
05 · ADVANCED ARGUMENTS

📚 *args & **kwargs

*args allows a function to receive multiple positional arguments, while **kwargs allows multiple keyword arguments. 

def total(*numbers):

    return sum(numbers)

print(total(10, 20, 30))

def student(**details):

    print(details)

student(
    name="Varalakshmi",
    course="Data Science"
)
💡 Interview Tip: Remember:

*args → multiple positional arguments
**kwargs → multiple keyword arguments
06 · SHORT FUNCTIONS

⚡ Lambda Functions

A lambda function is a small anonymous function written using the lambda keyword. 

square = lambda x: x * x

print(square(5))
💡 Interview Tip: Lambda functions are useful when a small function is needed for a short operation.
07 · CODE ORGANIZATION

📦 Modules

A module is a Python file containing functions, variables or classes that can be reused in another Python program. 

import math

result = math.sqrt(25)

print(result)
💡 Interview Tip: Modules help organize code and allow us to reuse functionality across different programs.
