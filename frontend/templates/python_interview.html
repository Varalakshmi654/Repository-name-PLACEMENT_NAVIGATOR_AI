📚 01 · Theory Questions

QUESTION 01

What is Python?

Python is a high-level, interpreted programming language known for its simple and readable syntax. It is widely used in web development, data analysis, automation, machine learning and artificial intelligence.
QUESTION 02

What are Python's main data types?

Common Python data types include int, float, str, bool, list, tuple, set and dictionary.
QUESTION 03

What is the difference between a list and a tuple?

A list is mutable, which means its elements can be changed after creation. A tuple is immutable, so its elements cannot normally be changed after creation.
QUESTION 04

What is a dictionary in Python?

A dictionary stores data as key-value pairs. 
student = {
    "name": "Varalakshmi",
    "course": "Data Science"
}

print(student["name"])
QUESTION 05

What is the difference between == and = ?

The = operator is used for assignment, while == is used to compare two values.

🧩 03 · Scenario Questions

SCENARIO 01

You have a list containing duplicate values. How would you remove duplicates?

One simple approach is to convert the list into a set because a set stores unique values. 
numbers = [1, 2, 2, 3, 3, 4]

unique_numbers = list(set(numbers))

print(unique_numbers)
SCENARIO 02

Your program is producing an error. What would you do first?

First, I would read the error message carefully, identify the line causing the problem, understand the type of error and then debug the code step by step.
SCENARIO 03

If a loop is running continuously, what would you check?

I would check the loop condition and verify whether the variable controlling the condition is being updated. An incorrect condition or missing update can cause an infinite loop.
