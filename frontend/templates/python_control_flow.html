Conditions & Loops

Learn how Python makes decisions and repeats operations using conditions and loops.

🎯 What You Will Learn

if, elif, else, for loops, while loops, break and continue statements.

01 · DECISION MAKING

🔀 if / elif / else

Conditional statements allow a program to make decisions based on whether a condition is true or false. 

marks = 85

if marks >= 90:

    print("Excellent")

elif marks >= 60:

    print("Good")

else:

    print("Needs Improvement")
💡 Interview Tip: Use if for the first condition, elif for additional conditions, and else when none of the previous conditions are true.
02 · LOOPING

🔁 for Loop

A for loop is used to iterate over items in a sequence such as a list, string or range. 

numbers = [10, 20, 30, 40]

for number in numbers:

    print(number)
💡 Interview Tip: Use a for loop when you want to iterate through a known sequence or collection.
03 · LOOPING

🔄 while Loop

A while loop repeatedly executes a block of code as long as its condition remains true. 

count = 1

while count <= 5:

    print(count)

    count += 1
💡 Interview Tip: A while loop is useful when the number of iterations depends on a condition.
04 · LOOP CONTROL

🛑 break

The break statement immediately stops the loop. 

for number in range(1, 10):

    if number == 5:

        break

    print(number)
💡 Remember: break → completely exits the loop.
05 · LOOP CONTROL

⏭️ continue

The continue statement skips the current iteration and moves to the next iteration. 

for number in range(1, 6):

    if number == 3:

        continue

    print(number)
💡 Remember: continue → skips the current iteration.
06 · USEFUL FUNCTION

🔢 range()

The range() function generates a sequence of numbers and is commonly used with loops. 

for i in range(1, 6):

    print(i)
💡 Interview Tip: Remember that the stop value in range(start, stop) is not included.
🧠 QUICK REVISION

Control Flow Cheat Sheet

if → condition elif → another condition else → fallback for → sequence iteration while → condition-based loop break → stop loop continue → skip iteration

🎤 Control Flow Interview Questions

Practice explaining these concepts clearly in interview English.

01. What is the difference between if and elif?

The if statement checks the first condition. The elif statement allows us to check additional conditions when the previous condition is false.

02. What is the difference between for and while loops?

A for loop is commonly used to iterate over a sequence, while a while loop continues executing as long as its condition is true.

03. What is the difference between break and continue?

Break completely terminates the loop. Continue skips the current iteration and moves to the next iteration.

04. What is range() used for?

The range() function generates a sequence of numbers and is frequently used with for loops.
